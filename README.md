
# Smart Shopping Cart 🛒

## 📌 Project Overview
The Smart Shopping Cart is an intelligent shopping system designed to make the shopping experience easier, faster, and more convenient.

The system allows customers to place products in a smart cart, automatically detect the selected products, calculate the total price, and complete the checkout process using electronic payment.

## 🎯 Project Objectives
- Make shopping faster and easier.
- Automatically detect added products.
- Calculate the total shopping cost.
- Reduce manual checkout time.
- Support electronic payment.

## ⚙️ Main Features
- Product detection.
- Product list display.
- Automatic price calculation.
- Shopping cart management.
- Checkout system.
- Electronic payment.

## 🔧 Hardware Components
- Microcontroller / Control Board.
- Weight Sensors.
- Electronic Circuit.
- Display Device.
- Power Supply.

## 💻 Software Components
- User Interface.
- Product Management System.
- Price Calculation System.
- Checkout System.
- Payment Integration.
